## 1. 设计理念

- **一张卡片 = 一张明信片**：照片是主角，留白是纸，日期是邮戳，标签是贴纸。
- **明亮但不刺眼**：暖白纸面 + 天空蓝渐变背景，靠留白和阴影分层，不用重色块。
- **轻快**：圆角 24 / 虚线 / 微倾斜的邮戳，全部是旅行手账的语言。

## 2. 首页「明信片墙」

### 2.1 卡片解剖（7 层）

| | 内容 | 说明 |
|---|---|---|
| ① | **照片区** | 主图 4:3、圆角 16；≥3 张时右侧竖排两条缩略 + `+N` |
| ② | **邮戳** | 虚线圆 + `09·05` + 城市拼音（如 `SHENZHEN`），-11° 倾斜压在照片右上 |
| ③ | **地点** | 21pt 加粗；城市/坐标跟在后面用暖金小字（📍 深圳） |
| ④ | **见闻** | 最多两行，超出省略 |
| ⑤ | **虚线** | 明信片的"地址线"，分隔正文与底部信息 |
| ⑥ | **标签 / 日期** | 标签沿用现有确定性配色；日期用**等宽字** `2026.09.05`，像票根打印 |
| ⑦ | **待同步** | 照片左上角小白胶囊「☁︎ 图片待同步」，文案与逻辑不变 |

### 2.2 三种卡片形态

- **A · 多图明信片**（≥2 张）：主图 + 右侧竖排缩略 + `+N`，一眼看出"这趟拍了很多"。
- **B · 单图明信片**（1 张）：整幅 4:3 大图，最容易出效果。
- **C · 票根**（无照片）：淡蓝→暖白渐变 + 右侧邮票虚线框「照片待补」，不留空灰块。

### 2.3 色板

| 用途 | 色值 |
|---|---|
| 纸面 | `#FFFDF8`（描边 `#F0E9DC`） |
| 天空（页面背景渐变起点） | `#EAF4FF` |
| 阳光（主色，沿用现有 primary） | `#E9A73C` |
| 薄荷 | `#35B79A` |
| 珊瑚 | `#FF7A59` |
| 葡萄 | `#8B7BE8` |
| 墨（正文） | `#23292F`（次级 `#6B7681`，弱 `#9AA4AE`） |
| 标签配色 | 沿用 `tagColors.ts` 的确定性配色：海边=青、日落=橙、周末=绿、夜景=紫、日出=蓝 |

### 2.4 规格

卡片圆角 24、照片圆角 16、标签胶囊 999；阴影 `0 10 26 rgba(35,41,47,.10)`，轻阴影 `0 4 14 rgba(35,41,47,.07)`；
字体沿用 PingFang SC，日期与数字用等宽（SF Mono / Menlo）。

### 2.5 动效（轻，不闹）

- 列表进入：每张卡片 fade + 上移 12px，间隔 40ms 错开
- 按下：缩放 0.985 + 阴影收紧（150ms）
- 标签选中：弹簧回弹 0.94 → 1
- 下拉刷新：顶部出现一枚旋转的邮戳（可选增强）

## 3. 相册页（足迹详细页）「旅行日记页」

### 3.1 页面结构

| | 内容 | 说明 |
|---|---|---|
| ① | **票头** | 地点大字 26pt + 城市小字 + 标签贴纸；右侧一枚邮戳圆章（年份 / `09·05` / 城市拼音，-9° 倾斜）——与首页卡片上的邮戳是同一枚的放大版 |
| ② | **见闻卡** | 明信片背面留言感：纸卡 + 左侧渐变色条 + 结尾一行等宽小字署名（用拍摄时间） |
| ③ | **照片墙** | 拍立得：白边、底部留白写拍摄时间 + 序号、±1.1~1.3° 交错倾斜、两列错落 |
| ④ | **底部工具条** | 左「共 N 张 / 拍摄日期」，右「下载原图」（沿用现有下载逻辑） |
| ⑤ | **空态** | 邮票虚线框「照片待补」+ 一句引导 +「去添加照片」，不留空灰块 |

导航栏右上角新增一枚圆形 ✎ **「编辑这条足迹」**入口（当前相册页没有编辑入口，只能回列表长按）。

### 3.2 照片墙两种排法 → 已选 A

- **方案 A · 拍立得两列（已采纳）**：最有明信片/手账感，每屏约 4 张，翻看有节奏；代价是比三列少看几张。
- **方案 B · 三列规整（未采纳）**：信息密度高、找图快，只给照片加白边圆角、不倾斜；缺点是偏"相册表格"，旅行感弱。

### 3.3 与首页的呼应

- 首页卡片上的邮戳点进来 = 详情页票头的同一枚邮戳放大版，形成"点开一张明信片"的连续感。
- 标签沿用同一套确定性配色，两页颜色一致。
- 照片墙里的照片就是首页卡片照片的"全展开"，点开仍是现有全屏预览（手势、横屏、循环、下载都不动）。

### 3.4 动效

- 票头与邮戳：进入 fade + 邮戳轻微"盖章"（scale 1.15 → 1，120ms）
- 照片墙：逐张 fade + 上移 10px，间隔 30ms
- 点照片：沿用现有全屏预览转场，不新增动画
